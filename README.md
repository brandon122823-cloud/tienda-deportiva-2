## 📝 Acerca del Proyecto

**Richard's Style** busca brindar una experiencia de compra fluida, moderna e intuitiva para atletas y entusiastas del deporte. El sistema permite explorar catálogos por categoría, gestionar un carrito de compras y realizar pedidos de manera eficiente.

---

## ✨ Características Principales

* **Catálogo interactivo:** Filtros por categoría (calzado, ropa, accesorios, disciplina deportiva).
* **Buscador integrado:** Búsqueda rápida de productos por nombre o marca.
* **Carrito de compras:** Gestión de artículos en tiempo real, cálculo de totales e impuestos.
* **Diseño Responsive:** Adaptado a dispositivos móviles, tablets y escritorio.
* **Autenticación de usuarios:** Registro, inicio de sesión y gestión de perfiles.
